# Система бронирования рабочих мест

Учебный дипломный проект, разработанный для автоматизации учета и бронирования рабочих мест. Система позволяет пользователям выбирать доступные места, оформлять бронирование и управлять расписанием.

## Стек технологий

* **Java**
* **Spring Boot**
* **Spring Data JPA / Hibernate**
* **База данных** (H2 / MySQL)
* **Gradle**

## Основной функционал
* Регистрация и авторизация пользователей.
* Просмотр доступных рабочих мест.
* Создание, просмотр и отмена бронирования.
* Управление данными через REST API.
